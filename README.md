# 할 일 목록

오늘 할 일을 기록하고 완료한 항목을 체크하면 목표 달성률을 확인할 수 있는 웹 프로그램입니다. PC와 스마트폰 브라우저에서 사용할 수 있습니다.

[할 일 목록 열기](https://cy948201-a11y.github.io/todo-list/)

## 사용 방법

1. 입력창에 할 일을 적고 **추가**를 누릅니다.
2. 끝낸 일은 왼쪽 체크박스를 누릅니다. 위쪽에 완료 개수와 달성률이 표시됩니다.
3. **전체**, **미완료**, **완료** 버튼으로 원하는 항목만 볼 수 있습니다.
4. 지우려는 항목 오른쪽의 **삭제**를 누릅니다.

목록은 사용 중인 브라우저에 자동 저장됩니다. 같은 브라우저에서 다시 열면 이전 목록이 나타나며, 스마트폰과 PC의 목록은 각각 관리됩니다.
